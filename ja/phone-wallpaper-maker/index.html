スマホ壁紙メーカー：小さな花と手書きの英語で、機種にぴったりの壁紙に

ひとことで言うと：ロック画面やホーム画面の壁紙を無料で作れるツールです。やさしいくすみカラーの背景を選び、花と飾り方（マステ留め・リボン結び・ラッピング・鉢植え）を決めて、英語をひとこと打つときれいな手書き文字になります。サイズはお使いのスマホに自動で合わせます。イラストはすべて編織日和のオリジナルで、透かしも入りません。

スマホ壁紙メーカーの使い方（5ステップ）

  1. 機種を確認：スマホで開くと画面の解像度を自動で使います。パソコンで作るときは、壁紙を使う機種をリストから選んでください。
  2. 背景の色を選ぶ：さくら、セージ、空色など、やさしいくすみカラーが12色。好きな色を使いたいときは「背景色をカスタマイズ」から。
  3. 花と花の色を選ぶ：野の花、カーネーション、木蓮、デイジー、ラベンダー、かすみ草、バラ、ピンポンマム、ひまわり、またはミックス。花の色はおまかせでも、自分で選んでもOK。
  4. 飾り方を選ぶ：一輪、マステ留め、リボン結び、ラッピング、鉢植え、枝もの、文字だけ。「並びを変える」で配置が変わります。
  5. 英語をひとこと入れて保存：文字は自由に入力できます（名前、記念日、好きなひとこと）。用意した言葉をタップしてもOK。フォントや流れる線、小さなハートを選んで「スマホに保存」。

ロック画面の壁紙に設定する方法

機種手順
iPhone「写真」で画像を開く →「共有」→「壁紙に設定」→ 時計の位置を確認して「追加」。ロック画面を長押しして「＋」から追加することもできます。
Android（Pixel）ホーム画面の何もないところを長押し →「壁紙とスタイル」→「壁紙を変更」→「マイフォト」で画像を選び、ホーム画面・ロック画面・両方から選択。
Samsung Galaxy「ギャラリー」で画像を開く → 右下の「⋮」→「壁紙に設定」→ ロック画面・ホーム画面・両方から選択。

メニュー名はOSのバージョンによって少し違います。「壁紙」という項目を探してください。

かわいく仕上げるコツ

言葉は短めに。英語2〜4語くらいが手書き文字でいちばんきれいに見えます。用意した15の言葉は「stay gold」「you are doing great」など、短くてやさしいものばかりです。

ホーム画面は控えめに。アプリのアイコンが重なるので、一輪や鉢植えがおすすめ。花束はロック画面で映えます。

文字は「花の下」がいちばん安全。上は時計とウィジェット、中央は通知に隠れやすい場所です。

よくある質問

作った壁紙は自由に使ったりシェアしたりできますか？

はい。花、マスキングテープ、リボン、包装紙、鉢はすべて編織日和がプログラムで描いたオリジナルのイラストです。壁紙として使う、友だちに送る、SNSに載せるのは自由です。画像そのものの販売はご遠慮ください。

手書きフォントは商用でも使えますか？

Sacramento、Allura、Homemade Apple、Caveat の4つは Google Fonts のフォントで、SIL Open Font License（OFL）のもと商用を含めて無料で使えます。

日本語も入れられますか？

入れられますが、手書きフォントは英字のみ対応のため、日本語は端末の明朝体で表示されます。手書きの雰囲気にしたいときは英語がおすすめです。

どのサイズを選べばいいですか？

お使いの機種を選ぶだけで、画面と同じ解像度のPNGを書き出します（例：iPhone 16 は 1179×2556）。リストにない場合はいちばん近いサイズを選べば、壁紙に設定するときにスマホが自動で調整します。

「スマホに保存」を押してもダウンロードされません

スマホでは共有メニューが開くので、「画像を保存」を選んでください。ファイルの共有に対応していないブラウザでは画像が表示されるので、長押しして「写真に追加」または「画像をダウンロード」を選びます。

ロック画面の時計に文字が隠れませんか？

「ロック画面の時計を表示」をオンにすると、時計と下のボタンのおおよその位置を確認できます（保存する画像には入りません）。いちばん安全なのは「花の下」です。

画像はアップロードされますか？

されません。壁紙はブラウザの中で描かれ、文字も画像も送信されません。次回のために前回の設定だけをこの端末に保存します。

花や機能のリクエストはできますか？

もちろんです。追加してほしい花や飾り方、フォントなどのアイデアは newsletters@knittinghiyori.com までお送りください。ピンポンマムとひまわりもリクエストから追加しました。

友だちに同じ壁紙を作ってもらうには？

「この設定を友だちに送る」を押してリンクを送ってください。同じ背景・花・飾り方・文字で開き、サイズは友だちのスマホに合わせて変わります。

スマホ壁紙メーカーをホーム画面に追加

ホーム画面に追加すると、アプリのように開けます。ダウンロード不要で容量もとりません。気分を変えたいときにすぐ新しい壁紙を作れます。

iPhone：ホーム画面に追加（Safari）

  1. Safari でこのページを開く
  2. アドレスバー横の「共有」アイコンをタップ（四角と上向き矢印。新しい iOS では先に「⋯」をタップ）
  3. 下にスクロールして「ホーム画面に追加」をタップ
  4. 名前を変更して「追加」をタップ

iPhone：お気に入りに追加

  1. 同じく「共有」アイコンをタップ
  2. 「お気に入りに追加」をタップすると、Safari の新規タブからすぐ開けます

iPhone：ホーム画面に追加（Chrome）

  1. Chrome でこのページを開く
  2. アドレスバー右側の「共有」アイコンをタップ（見つからない場合は右下の「⋯」→「共有」）
  3. 下にスクロールして「ホーム画面に追加」をタップ
  4. 「追加」をタップするとホーム画面にアイコンが表示されます

iPhone：Chrome のブックマークに追加

  1. 右下の「⋯」をタップ
  2. 「ブックマークに追加」をタップ（☆アイコンの場合もあります）

Chrome の「ホーム画面に追加」は iOS 16.4 以降が必要です。表示されない場合は Safari で一度追加してください。

Android：ホーム画面に追加（Chrome）

  1. Chrome でこのページを開く
  2. 右上の「⋮」メニューをタップ
  3. 「ホーム画面に追加」をタップし、「追加」または「ショートカットを作成」を選択

Android：ブックマークに追加

  1. 右上の「⋮」をタップ
  2. 上段の☆をタップ

Samsung Internet：下部の「≡」→「ページを追加」→「ホーム画面」。

パソコン：ブックマークに追加

  1. Windows は Ctrl＋D、Mac は ⌘＋D
  2. 保存先を「ブックマークバー」にすると、ワンクリックで開けます
セキュリティ上、ウェブサイトから自動で追加することはできません。上の手順なら約10秒で完了します。

気に入ったら、壁紙をよく変える友だちにシェアしてください。シェアしてもらえることが、無料ツールへのいちばんの応援です。
