旅行の割り勘計算機：立て替えを記録して、誰が誰にいくら払うか自動計算

ひとことで：旅行費用を割り勘する無料ツールです。誰が何を立て替えたかを記録すると、通貨を自動で換算し、送金回数が最も少なくなる精算方法を出します（N人なら最大N−1回）。リンクを共有すれば、全員が同じ帳簿を見られます。

旅行の割り勘計算機の使い方（3ステップ）

  1. メンバーを追加し、精算通貨を選ぶ：一緒に旅行する全員を追加します。精算通貨は、帰国後に送金しやすい普段使いの通貨がおすすめです。
  2. 支払いのたびに1件ずつ記録：金額・現地の通貨・内容を入力し、誰が立て替えたかを選んで、割り勘する人にチェックを入れます。参加していない人はチェックしなければ負担しません。
  3. 精算結果を確認して、リンクを送る：精算欄に「誰が誰にいくら払うか」がすぐに表示されます。「リンクをメンバーに共有」でLINEグループなどに送れば、全員が同じ内容を確認できます。

計算のしくみ：差額方式で送金回数を最小に

各メンバーの差額＝実際に立て替えた金額－負担すべき金額です。プラスの人は受け取る側、マイナスの人は支払う側になります。いちばん多く払うべき人と、いちばん多く受け取るべき人から順に組み合わせて精算するので、N人なら送金は最大でN－1回で済みます。1件ごとにお金をやり取りする必要はありません。

例：たくや・けん・ゆいの3人で東京へ。たくやがホテル代¥60,000、けんが食事代¥15,000を立て替えました。3人で均等に割ると、1人あたり¥25,000です。

メンバー立て替え負担額差額
たくや¥60,000¥25,000＋¥35,000（受け取り）
けん¥15,000¥25,000－¥10,000（支払い）
ゆい¥0¥25,000－¥25,000（支払い）

送金は2回だけ：ゆいがたくやに¥25,000、けんがたくやに¥10,000を送れば精算完了です。精算通貨を別の通貨にした場合は、設定したレートで換算した金額が表示されます。

複数通貨の割り勘、為替レートはどれを使う？

初期設定では国際的な参考レート（仲値）を読み込みます。「市場レートで計算しよう」と事前に決めている場合に向いています。より正確にしたいときは、クレジットカードの明細に記載されたレートや、出発前に両替したときのレートに変更できます。レートは共有リンクに保存されるので、メンバー全員が同じ金額を見られます。

旅行の割り勘・よくある質問

旅行の割り勘、いちばん公平な計算方法は？

よく使われるのは差額方式です。各自の「実際に払った金額」から「負担すべき金額」を引いて差額を出し、プラスの人が受け取り、マイナスの人が支払います。その差額を、できるだけ少ない送金回数で精算します。

違う通貨で支払った費用はどう割り勘する？

まず精算通貨を1つ決め、外貨の支出をすべてその通貨に換算してから割ります。このツールは参考レートを読み込めるほか、実際のカードのレートや両替レートに手動で変更することもできます。

共有リンクでデータがサーバーに送られる？

送られません。帳簿のデータは圧縮されてリンクの「#」以降に入るだけで、リンクとお使いのブラウザの中にしか保存されません。サイトのサーバーが支出内容を受け取ったり保存したりすることはありません。

参加していない費用は負担しなくてもいい？

できます。支出ごとに「誰で割るか」を選べて、チェックした人だけで均等に負担します。たとえば、お酒を飲まない人は飲み代を負担しない、といった設定ができます。

送金回数が思ったより少ないのはなぜ？

1件ずつお金をやり取りするのではなく、各自の支払いと負担をすべて相殺して差額だけを残し、最も大きな支払い額と受け取り額から順に組み合わせるためです。N人なら、送金は通常最大でN－1回です。

旅行の割り勘計算機をスマホのホーム画面に追加できる？

できます。iPhoneはSafariでこのページを開き「共有」→「ホーム画面に追加」、AndroidはChromeで「⋮」→「ホーム画面に追加」を選びます。アプリのようにホーム画面から開けて、ダウンロードは不要。帳簿もそのスマホに保存されます。

このツールを使っていないメンバーも結果を見られる？

見られます。「リンクをメンバーに共有」で送れば、相手はリンクを開くだけで帳簿全体と各自の送金額を確認でき、登録やインストールは不要です。「精算テキストをコピー」でLINEグループに貼り付けることもできます。

2人が別々のスマホで記録した帳簿をまとめられる？

まとめられます。それぞれ「リンクをメンバーに共有」で相手に送ってください。開くと同じ旅行だと判断され、両方の支出が統合されます。重複は自動でスキップされ、削除した支出が復活することもありません。統合したあとにもう一度リンクを共有すれば、全員が同じ帳簿になります。

誰が支払い済みかを記録するには？

精算結果の各送金の下にある「支払い済みにする」を押すと、その返済が記録され、残りの送金が自動で再計算されます。何件精算済みか、残りはいくらかも表示されます。その後に共有するリンクや精算テキストには支払い済みの人と未払いの人が表示されるので、もう払った人に催促してしまうこともありません。支払いの記録も、帳簿の統合と一緒にまとめられます。

Splitwiseなどの割り勘アプリとの違いは？

Splitwiseなどのアプリはメンバー全員のダウンロードと登録が必要で、長期的な記録に向いています。このツールはWebページを開くだけで使え、登録も不要です。メンバーはリンクを開くだけで同じ帳簿を見られるので、1回の旅行が終わったらすぐ精算したい場合に向いています。クラウドのリアルタイム同期はありませんが、各自が記録した帳簿をリンクで送り合えば統合できます。

アプリのダウンロードや登録は必要？

必要ありません。スマホやパソコンのブラウザで開くだけで使えます。データはブラウザに自動で保存され、共有リンクを使えば別の端末で続きを編集できます。

割り勘計算機をホーム画面に追加して、次の旅行ですぐ使おう

ホーム画面に追加すると、アプリのように開けます。ダウンロード不要で容量もとりません。帳簿はそのスマホのブラウザに保存されるので、続きからすぐ記録できます。

iPhone：ホーム画面に追加（Safari）

  1. Safari でこのページを開く
  2. アドレスバー横の「共有」アイコンをタップ（四角と上向き矢印。新しい iOS では先に「⋯」をタップ）
  3. 下にスクロールして「ホーム画面に追加」をタップ
  4. 名前を変更して「追加」をタップ

iPhone：お気に入りに追加

  1. 同じく「共有」アイコンをタップ
  2. 「お気に入りに追加」をタップすると、Safari の新規タブからすぐ開けます

iPhone：ホーム画面に追加（Chrome）

  1. Chrome でこのページを開く
  2. アドレスバー右側の「共有」アイコンをタップ（見つからない場合は右下の「⋯」→「共有」）
  3. 下にスクロールして「ホーム画面に追加」をタップ
  4. 「追加」をタップ。アイコンから Chrome で開きます

iPhone：Chrome のブックマークに追加

  1. 右下の「⋯」をタップ
  2. 「ブックマークに追加」をタップ（☆アイコンの場合もあります）

Chrome の「ホーム画面に追加」は iOS 16.4 以降が必要です。表示されない場合は Safari で一度追加してください。

Android：ホーム画面に追加（Chrome）

  1. Chrome でこのページを開く
  2. 右上の「⋮」メニューをタップ
  3. 「ホーム画面に追加」をタップし、「追加」または「ショートカットを作成」を選択
  4. ホーム画面にアイコンが表示されます

Android：ブックマークに追加

  1. 右上の「⋮」をタップ
  2. 上段の☆をタップ

Samsung Internet：下部の「≡」→「ページを追加」→「ホーム画面」。

パソコン：ブックマークに追加

  1. Windows は Ctrl＋D、Mac は ⌘＋D
  2. 保存先を「ブックマークバー」にすると、ワンクリックで開けます

パソコンで記録した帳簿は「リンクをメンバーに共有」でスマホに送れば、スマホで続きを記録できます。

セキュリティ上、ウェブサイトから自動で追加することはできません。上の手順なら約10秒で完了します。
