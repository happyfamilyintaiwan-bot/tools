YouTube 登録リンクメーカー：開くとすぐ「チャンネル登録」の確認が出るリンク

ひとことで：YouTube チャンネルの URL を貼ると、末尾に ?sub_confirmation=1 を自動で付けて「ワンタップ登録リンク」にします。まだ登録していない人が開くと、「このチャンネルを登録しますか？」とすぐ表示されます。ひと手間減らすだけで、登録してもらいやすくなります。

貼るだけで完成スマホ版 URL も自動で整理QR コード付き無料・登録不要ホーム画面に追加 ↓

1チャンネルの URL を貼る

@ハンドルだけでも大丈夫です。@ハンドル、/channel/UC…、/c/、/user/ の 4 種類に対応。スマホ版の URL や、末尾の /videos・?si= も自動で整理します。

こんな場所に貼れます：

  • 動画の概要欄の 1 行目、固定コメント
  • Instagram・Threads・TikTok のプロフィールリンク
  • メルマガやブログ記事の最後
  • LINE オープンチャットのお知らせ、メールの署名

YouTube のワンタップ登録リンクの作り方（3 ステップ）

  1. チャンネルの URL をコピー：自分のチャンネルページを開き、ブラウザのアドレスバーから URL をまるごとコピーします。ふつうは https://www.youtube.com/@ハンドル の形です。YouTube アプリなら、チャンネルページ右上の「⋮」→「共有」→「リンクをコピー」。
  2. 上の入力欄に貼る：スマホ版の URL や末尾の /videos、?si= を自動で取り除き、?sub_confirmation=1 を付けます。
  3. リンクをコピーして使う：「リンクをコピー」を押して、動画の概要欄、プロフィール、メルマガ、LINE に貼ります。印刷物には QR コードが便利です。

チャンネル URL の種類ごとの変換結果

貼った URLできあがる登録リンク
youtube.com/@ハンドルyoutube.com/@ハンドル?sub_confirmation=1
m.youtube.com/@ハンドル/videos?si=…youtube.com/@ハンドル?sub_confirmation=1
youtube.com/channel/UC…youtube.com/channel/UC…?sub_confirmation=1
youtube.com/c/名前、/user/名前youtube.com/c/名前?sub_confirmation=1
youtu.be/…、/watch?v=…、/shorts/…使えません：動画の URL なので、チャンネルの URL を貼ってください

4 種類どれでも使えます。いちばん読みやすく覚えやすいのは @ハンドルの URL です。

使う前に知っておきたい 3 つのこと

  1. まだ登録していない人にだけ表示されます。登録済みの人が開くと、ふつうのチャンネルページが表示されます。
  2. ブラウザで開くといちばん確実です。パソコンやスマホの Safari・Chrome では確認画面が中央に出ます。LINE や Instagram のアプリ内で開くと、YouTube アプリが直接起動して確認画面が出ないことがあります。
  3. テストは未登録のアカウントで。シークレットウィンドウで別アカウントにログインするか、友だちに開いてもらうと確認できます。

広告

YouTube 登録リンクのよくある質問

?sub_confirmation=1 とは何ですか？

YouTube が対応している URL パラメータです。チャンネル URL の末尾に付けると、まだ登録していない人がページを開いたときに「このチャンネルを登録しますか？」という確認がすぐ表示されます。あとは「登録」を押すだけです。

自分で開いても確認画面が出ないのはなぜ？

チャンネルのオーナーのアカウントでログインしているか、すでに登録済みだからです。シークレットウィンドウで、登録していない別のアカウントにログインして試してください。ログインしていない人には、先にログイン画面が表示されます。

動画の URL でも使えますか？

使えません。このパラメータはチャンネルの URL でだけ働きます。チャンネルページを開いて @ハンドルの URL をコピーしてください。動画の URL を貼ると、ツールがお知らせします。

LINE や Instagram から開くとどうなりますか？

アプリ内ブラウザから YouTube アプリが直接起動し、確認画面が出ないことがあります。確実に表示させたいなら、概要欄やメルマガなど、パソコンでもよく読まれる場所に置くのがおすすめです。

リンクに期限はありますか？有料ですか？

期限はなく、無料です。短縮 URL を通さないふつうの YouTube の URL なので、チャンネルの URL が変わらない限りずっと使えます。

ハンドルを変えたらどうなりますか？

古い @ハンドルの URL は使えなくなることがあるので、作り直してください。変更の心配をしたくない場合は、ずっと変わらない /channel/UC… の URL を使いましょう。YouTube Studio の「カスタマイズ」→「基本情報」で確認できます。

QR コードは印刷して使えますか？

使えます。中身は同じ登録リンクなので、名刺、チラシ、イベントのポスターなどに便利です。「QR コードを保存」を押すか、スマホでは画像を長押しして保存してください。

URL はアップロード・保存されますか？

されません。リンクはブラウザの中で作られ、サーバーには送られません。QR コードもお使いの端末の中で描いています。

登録リンクメーカーをホーム画面に追加

ホーム画面に追加すると、アプリのように開けます。ダウンロード不要で容量もとりません。概要欄や投稿を書くときにすぐ使えます。

iPhone：ホーム画面に追加（Safari）

  1. Safari でこのページを開く
  2. アドレスバー横の「共有」アイコンをタップ（四角と上向き矢印。新しい iOS では先に「⋯」をタップ）
  3. 下にスクロールして「ホーム画面に追加」をタップ
  4. 名前を変更して「追加」をタップ

iPhone：お気に入りに追加

  1. 同じく「共有」アイコンをタップ
  2. 「お気に入りに追加」をタップすると、Safari の新規タブからすぐ開けます

iPhone：ホーム画面に追加（Chrome）

  1. Chrome でこのページを開く
  2. アドレスバー右側の「共有」アイコンをタップ（見つからない場合は右下の「⋯」→「共有」）
  3. 下にスクロールして「ホーム画面に追加」をタップ
  4. 「追加」をタップするとホーム画面にアイコンが表示されます

iPhone：Chrome のブックマークに追加

  1. 右下の「⋯」をタップ
  2. 「ブックマークに追加」をタップ（☆アイコンの場合もあります）

Chrome の「ホーム画面に追加」は iOS 16.4 以降が必要です。表示されない場合は Safari で一度追加してください。

Android：ホーム画面に追加（Chrome）

  1. Chrome でこのページを開く
  2. 右上の「⋮」メニューをタップ
  3. 「ホーム画面に追加」をタップし、「追加」または「ショートカットを作成」を選択

Android：ブックマークに追加

  1. 右上の「⋮」をタップ
  2. 上段の☆をタップ

Samsung Internet：下部の「≡」→「ページを追加」→「ホーム画面」。

パソコン：ブックマークに追加

  1. Windows は Ctrl＋D、Mac は ⌘＋D
  2. 保存先を「ブックマークバー」にすると、ワンクリックで開けます
セキュリティ上、ウェブサイトから自動で追加することはできません。上の手順なら約10秒で完了します。
