把聚餐分帳計算機加到手機桌面，吃完飯直接開

加到主畫面後，它會像 App 一樣出現在手機桌面，不用下載、不佔空間，結帳時打開就能算。

iPhone：加到主畫面（Safari）

  1. 用 Safari 打開這一頁
  2. 點網址列旁的「分享」圖示（方框加向上箭頭；新版 iOS 可能要先點「⋯」）
  3. 往下滑，點「加入主畫面」
  4. 名稱可以改成「聚餐分帳」，再按「加入」

iPhone：加到我的最愛

  1. 一樣點「分享」圖示
  2. 點「加入我的最愛」，之後在 Safari 新分頁就能一鍵打開

iPhone：加到主畫面（Chrome）

  1. 用 Chrome 打開這一頁
  2. 點網址列右側的「分享」圖示（沒看到的話，點右下角「⋯」再選「分享」）
  3. 往下滑，點「加入主畫面」
  4. 按「加入」，桌面就會出現圖示

iPhone：加入 Chrome 書籤

  1. 點右下角「⋯」
  2. 點「加入書籤」（部分版本顯示為☆圖示）

iPhone 的 Chrome 需要 iOS 16.4 以上才有「加入主畫面」；沒有的話，改用 Safari 操作一次即可。

Android：加到主畫面（Chrome）

  1. 用 Chrome 打開這一頁
  2. 點右上角的「⋮」選單
  3. 點「加到主畫面」，出現視窗後選「新增」或「建立捷徑」

Android：加入書籤

  1. 點右上角「⋮」
  2. 點最上排的「☆」星號

Samsung 網際網路瀏覽器：點下方的「≡」選單 →「加入頁面至」→「主畫面」。

電腦：加入書籤

  1. Windows 按 Ctrl＋D，Mac 按 ⌘＋D
  2. 資料夾選「書籤列」，之後瀏覽器最上方就能一鍵打開
基於手機安全設計，網頁無法替你直接加入，照上面步驟約 10 秒完成。

覺得好用嗎？分享給常一起吃飯的朋友，下次結帳不用再拿計算機按半天。分享出去，就是給免費工具最好的鼓勵。
