YouTube 一鍵訂閱連結怎麼做？三步驟完成

  1. 複製頻道網址：打開你的 YouTube 頻道首頁，從瀏覽器網址列複製整段網址，通常長得像 https://www.youtube.com/@你的帳號。用手機 App 的話，點頻道頁右上角「⋮」→「分享」→「複製連結」。
  2. 貼到上面的輸入框：工具會自動整理網址（手機版、後面多的 /videos、?si= 分享碼都會拿掉），再加上 ?sub_confirmation=1。
  3. 複製連結，貼到要放的地方：按「複製連結」，貼到影片說明欄、社群簡介、電子報或 LINE。要印出來的話，用下面的 QR code。

不同的頻道網址，會變成什麼樣子？

你貼上的網址產生的一鍵訂閱連結
youtube.com/@帳號youtube.com/@帳號?sub_confirmation=1
m.youtube.com/@帳號/videos?si=…youtube.com/@帳號?sub_confirmation=1
youtube.com/channel/UC…youtube.com/channel/UC…?sub_confirmation=1
youtube.com/c/名稱、/user/名稱youtube.com/c/名稱?sub_confirmation=1
youtu.be/…、/watch?v=…、/shorts/…不能用：這些是影片網址，請改貼頻道網址

四種頻道網址都可以用，最推薦 @帳號 那種，好記又好看。

使用前要知道的三件事

  1. 只對還沒訂閱的人有效。已經訂閱的人點開，只會看到頻道首頁，不會再跳一次確認框。
  2. 在網頁瀏覽器裡效果最好。電腦版和手機的 Safari、Chrome 都會跳出置中的確認框；從 LINE、Instagram 這類 App 裡點開，有時會直接打開 YouTube App，確認框可能被略過。
  3. 自己測試要用沒訂閱的帳號。用無痕視窗、登入另一個帳號，或請朋友幫忙點，才看得到彈窗。

YouTube 訂閱連結常見問題

?sub_confirmation=1 是什麼？

這是 YouTube 官方支援的網址參數。頻道網址最後加上這一段，還沒訂閱的人打開時，YouTube 會直接跳出「要訂閱這個頻道嗎？」的確認框，對方只要再按一次「訂閱」就完成。

為什麼我自己點開沒有跳出訂閱框？

最常見的原因是你已經訂閱了自己的頻道，或用頻道擁有者的帳號登入。請用無痕視窗登入另一個沒訂閱的帳號再試一次。沒登入 YouTube 的人點開，會先被請去登入。

貼影片網址可以嗎？

不行。這個參數只對頻道網址有作用。請打開你的頻道首頁，複製 @帳號 那種網址再貼上；工具偵測到影片網址時，也會提醒你改貼頻道網址。

從 LINE 或 Instagram 點開會怎麼樣？

這些 App 的內建瀏覽器有時會直接喚醒 YouTube App，這時可能只看到頻道頁、不會跳出確認框。想要效果最穩定，可以在貼文裡提醒大家「用瀏覽器打開」，或放在電腦版也常看的地方，例如影片說明欄和電子報。

連結會過期嗎？要付費嗎？

不會過期，也完全免費。產生的就是一般的 YouTube 網址，沒有經過任何縮網址服務，只要頻道網址不變，就能一直用。

改了頻道帳號名稱，連結還能用嗎？

@帳號 改名之後，舊的 @帳號 網址可能失效，要重新產生一次。如果怕改名，可以改用 /channel/UC… 開頭的頻道 ID 網址，這個永遠不會變；在 YouTube Studio →「自訂」→「基本資訊」就找得到。

QR code 可以印出來用嗎？

可以。QR code 裡就是同一條一鍵訂閱連結，可以印在名片、講義、市集攤位或活動海報上。按「下載 QR code」存成圖片，手機上長按圖片也能存。

網址會被上傳或記錄嗎？

不會。網址是在你的瀏覽器裡轉換的，不會傳到我們的伺服器；QR code 也是在你的裝置上畫出來的。
