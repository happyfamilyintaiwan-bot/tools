手機桌布產生器怎麼用？五步驟完成

  1. 確認手機型號：用手機打開會自動抓這支手機的螢幕解析度；在電腦上做，就從選單選要放桌布的型號。
  2. 挑一個底色：12 種粉嫩的莫蘭迪色，例如櫻花粉、鼠尾草、霧藍；想用自己的顏色，打開「自訂底色」。
  3. 挑花和花的顏色：小野花、康乃馨、玉蘭、雛菊、薰衣草、滿天星、玫瑰、乒乓菊、向日葵，或選「綜合」混搭；花色可以自動搭配，也可以自己選。
  4. 挑擺法：一枝、紙膠帶、手綁緞帶、包裝花束、小盆栽、斜枝，或只放字。不喜歡目前的排法，按「換一種排法」。
  5. 加一句英文手寫字，存到手機：字可以自己填（名字、紀念日、任何一句英文都行），或點一句預設的鼓勵語，選字體、要不要兩側飄帶線和小愛心，再按「存到手機」。

做好的桌布，怎麼設成鎖定畫面？

手機設定步驟
iPhone打開「照片」選這張圖 → 點「分享」→「作為背景圖片」→ 確認時鐘位置後按「加入」，再選「設為背景圖片組合」或只用在鎖定畫面。也可以在鎖定畫面長按 →「＋」新增。
Android（Pixel）在主畫面空白處長按 →「桌布和樣式」→「更換桌布」→「我的相片」，選這張圖後設為主畫面、鎖定畫面或兩者。
Samsung Galaxy打開「媒體瀏覽器」選這張圖 → 右下「⋮」→「設為桌布」→ 選鎖定螢幕、主螢幕或兩者。

各家手機的選單名稱會因系統版本略有不同，找「桌布」或「背景圖片」就對了。

手機桌布產生器常見問題

做出來的桌布有版權問題嗎？可以分享嗎？

花、紙膠帶、緞帶、包裝紙和花盆都是編織日和自己用程式畫的原創插畫，沒有使用別人的圖。你可以自由當手機桌布、分享給朋友、貼到社群；請不要把圖片本身拿去販售。

手寫字體是哪裡來的？可以商用嗎？

四款手寫字體 Sacramento、Allura、Homemade Apple、Caveat 都來自 Google Fonts，採用 SIL Open Font License（OFL）開源授權，可以免費使用，包含商業用途。

可以打中文或日文嗎？

可以打，但這四款手寫字體只有英文字母，中文和日文會改用手機內建的明體顯示，看起來不會是手寫風。想要手寫感，建議打英文，或直接點一句預設的鼓勵語。

存下來的圖片尺寸要選多大？

選你手機的型號就好，工具會輸出和螢幕解析度一樣的 PNG，例如 iPhone 16 是 1179×2556。清單裡沒有你的型號時，選尺寸最接近的，手機設定桌布時會自動縮放。

為什麼按了「存到手機」沒有下載？

手機上會跳出分享選單，請選「儲存影像」或「儲存到相簿」。如果你的瀏覽器不支援分享檔案，會改成顯示圖片，長按圖片選「加入照片」或「下載圖片」就能存。

字會不會被鎖定畫面的時鐘擋住？

預覽上可以打開「預覽鎖定畫面時鐘」，看到時鐘和下方按鈕的大概位置（不會印在圖上）。字選「花上面」也會排在時鐘下方；最保險的是放「花下面」。

可以在電腦上做，再傳到手機嗎？

可以。在電腦上選好手機型號，按「存到手機」會下載 PNG，再用 AirDrop、LINE 或雲端硬碟傳到手機即可。也可以按「把這組設定分享給朋友」，把連結傳給自己，用手機打開就是同一張。

圖片會上傳到網路嗎？

不會。桌布是在你的瀏覽器裡畫出來的，文字和圖片都不會上傳；工具只會在這支手機記住你上次的設定，方便下次接著改。

想要更多花或功能，可以跟你說嗎？

當然可以！有想加的花、擺法、字體或任何建議，歡迎寄信到 newsletters@knittinghiyori.com，乒乓菊和向日葵就是這樣加進來的。

朋友想要跟我一樣的桌布，怎麼做？

按「把這組設定分享給朋友」，朋友打開連結就會套用同一組底色、花、擺法和手寫字，尺寸會自動換成他自己的手機。

把手機桌布產生器加到手機桌面，想換桌布時直接開

加到主畫面後，它會像 App 一樣出現在手機桌面，不用下載、不佔空間，想換心情時打開就能做一張新的。

iPhone：加到主畫面（Safari）

  1. 用 Safari 打開這一頁
  2. 點網址列旁的「分享」圖示（方框加向上箭頭；新版 iOS 可能要先點「⋯」）
  3. 往下滑，點「加入主畫面」
  4. 名稱可以改成「桌布產生器」，再按「加入」

iPhone：加到我的最愛

  1. 一樣點「分享」圖示
  2. 點「加入我的最愛」，之後在 Safari 新分頁就能一鍵打開

iPhone：加到主畫面（Chrome）

  1. 用 Chrome 打開這一頁
  2. 點網址列右側的「分享」圖示（沒看到的話，點右下角「⋯」再選「分享」）
  3. 往下滑，點「加入主畫面」
  4. 按「加入」，桌面就會出現圖示

iPhone：加入 Chrome 書籤

  1. 點右下角「⋯」
  2. 點「加入書籤」（部分版本顯示為☆圖示）

iPhone 的 Chrome 需要 iOS 16.4 以上才有「加入主畫面」；沒有的話，改用 Safari 操作一次即可。

Android：加到主畫面（Chrome）

  1. 用 Chrome 打開這一頁
  2. 點右上角的「⋮」選單
  3. 點「加到主畫面」，出現視窗後選「新增」或「建立捷徑」

Android：加入書籤

  1. 點右上角「⋮」
  2. 點最上排的「☆」星號

Samsung 網際網路瀏覽器：點下方的「≡」選單 →「加入頁面至」→「主畫面」。

電腦：加入書籤

  1. Windows 按 Ctrl＋D，Mac 按 ⌘＋D
  2. 資料夾選「書籤列」，之後瀏覽器最上方就能一鍵打開
基於手機安全設計，網頁無法替你直接加入，照上面步驟約 10 秒完成。
